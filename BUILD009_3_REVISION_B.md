# Build009.3 Revision B — Related Process Engine

## Implemented
- Automatic Related Process scoring based on canonical cross-language tags.
- Editorial relationship hints act as boosts, not the sole source of recommendations.
- Independent Geopolitical Technology Control World Process.
- Localized relationship labels and localized “Why related” explanations.
- Connection score, shared concepts, and editorial confirmation in the Connections screen.
- World Process cards now show automatic score and explanation.

## Scoring signals
- Shared system concepts.
- Editorially confirmed dependencies.
- Reverse relationships.
- Cross-domain bridge bonus.
- Update-time proximity.

The repository exposes both `getConnected()` for backwards compatibility and `getRelated()` for the new engine.
