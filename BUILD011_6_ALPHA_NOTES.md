# Build011.6 Alpha — AI Editorial Console

## Entry
Long-press the date on the first page for about 1.2 seconds.

## Included
- In-app Research → Analyze → Write pipeline
- Step status and real API errors
- Research and Publish token inputs stored on the current device
- Analyst decision summary
- Writer six-page title preview
- Normal approve, human override approve, and reject
- Remote-content refresh after publishing
- Remote source, version, and last-sync status

## Alpha limitations
- Tokens use AsyncStorage in this Expo/Snack-compatible alpha, not OS secure storage.
- Pipeline state is held in memory and resets when the app reloads.
- Duplicate-publish protection remains a backend follow-up.
