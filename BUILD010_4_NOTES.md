# Build010.4 — Daily Continuity

Build010.4 completes the daily loop by connecting today's decision with the user's previous reading state.

## Added
- Daily continuity model and repository.
- “You last saw / Added since then / Current judgment” continuity summary.
- Uses LivingMemory's last read Insight for each World Process when available.
- Falls back to the previous meaningful Insight when no personal reading memory exists.
- Continuity summary appears on the No New Global Insight landing page.
- A compact continuity summary appears on page 6 of published or updated Insights.
- English, Chinese and Japanese copy.

## Product behavior
The user no longer needs a separate My World page to understand continuity. Personal context is placed directly in the daily reading flow.
