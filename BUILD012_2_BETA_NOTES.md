# Build012.2 Beta — Historical Chapter Focus

The Alpha version linked History to the correct World Process, but did not carry the selected historical Insight into that page.

This build adds:

- `focusInsightId` in the process navigation route
- automatic scroll to the selected historical chapter
- a visible chapter-position banner
- visual highlighting of the selected chapter
- a “you entered here” marker
- Back returns to History because the process page is pushed over History instead of replacing it
- normal left-swipe entry still opens the World Process from the top
